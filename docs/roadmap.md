# Roadmap

## Fase 1 · Fundación (alcance de esta entrega)

Landing Cloud, shell del dashboard, estados de funcionalidades futuras, branding disponible, tokens, herramientas de calidad, pruebas y esquema inicial. El logo original ya está integrado desde su PDF vectorial. Los motores y el esquema de Prisma también fueron verificados en el entorno restaurado; ver progreso.

## Fase 2 · Autenticación y multiempresa (siguiente paso, no implementado)

Definir proveedor de identidad y flujo de registro seguro. Crear empresas y membresías autorizadas. Resolver contexto de tenant en servidor, roles y permisos. Probar aislamiento entre empresas y revocación de acceso. Reemplazar selector de muestra y bloquear las rutas operativas a usuarios no autorizados, preservando una demo explícita si se desea. Preparar migraciones revisadas en una base de desarrollo.

## Fases posteriores · Por definir y autorizar

1. Integración oficial Meta Cloud API, validación de webhooks, idempotencia y estados de mensajes.
2. Conversaciones, contactos y colaboración humana.
3. Agentes IA y conocimientos, presupuestos de consumo, costos y escalamiento.
4. Worker Redis/BullMQ, automatizaciones y herramientas externas.
5. Analíticas verificables, CRM comercial, suscripciones y facturación.

No son fechas de entrega ni funciones disponibles. Ninguna fase posterior se inicia automáticamente; los despliegues de producción necesitan autorización explícita.
